# MaryVFS — эмулятор командной оболочки UNIX

Эмулятор командной оболочки UNIX-подобной ОС с графическим интерфейсом (JavaFX).
Работает с виртуальной файловой системой (VFS), загружаемой из JSON-файла.
Все операции производятся **в памяти**, исходные данные VFS не модифицируются.

---

## Возможности

- **GUI на JavaFX** — окно с полем вывода и прокруткой.
- **REPL** — диалог с пользователем: ввод команды, вывод результата, приглашение `~> `.
- **Парсер аргументов** с поддержкой кавычек (`cd "My Documents"`).
- **Конфигурация через параметры командной строки**:
    - `VFS="<path>"` — путь к JSON-файлу VFS,
    - `SCRIPT="<path>"` — путь к стартовому скрипту.
- **VFS из JSON** — дерево файлов и папок в памяти, поддержка base64 для бинарных данных.
- **motd** — приветственное сообщение из корня VFS при старте.
- **Стартовые скрипты** — поддержка комментариев (`/**/`, `//`), имитация диалога.
- **Обработка ошибок** — неизвестная команда, неверные параметры, файл не найден, битый JSON.

## Команды

| Команда | Описание |
|---|---|
| `ls` | список файлов и папок в текущей директории |
| `cd "<dir>"` | перейти в директорию |
| `cd ".."` | подняться на уровень вверх |
| `find "<pattern>"` | рекурсивный поиск по имени или маске (`*`, `?`) |
| `du` | размер директории в битах |
| `cal` | календарь текущего месяца |
| `cal "<year>"` | календарь на год |
| `cal "<month> <year>"` | календарь на месяц |
| `cal "<day> <month> <year>"` | календарь с подсветкой дня |
| `chown "<user>" "<path>"` | сменить владельца |
| `chown "<user>:<group>" "<path>"` | сменить владельца и группу |
| `chown "-R" "<user>" "<dir>"` | сменить владельца рекурсивно |
| `conf-dump` | вывести параметры эмулятора |
| `exit` | выход |

## Сборка и запуск

### Требования

- JDK 17+
- Maven 3.8+
- JavaFX 17 (подтягивается через Maven)
- - `make` (GNU Make) — для запуска через Makefile
- Linux/macOS: `sudo apt install make` / `brew install make`
- Windows: `choco install make` или MSYS2
